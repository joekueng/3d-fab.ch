# Homepage 3DBenchy illustrations

The smooth gray digital model is rendered from the original 3DBenchy STL by Daniel Norée / Creative Tools (CC0 1.0): https://github.com/CreativeTools/3DBenchy and https://www.3dbenchy.com/license/ . Rendered with Blender; it has no FDM layer texture.

benchy-sketch-draft.png and benchy-printed-yellow.png are transparent illustrations generated with the built-in image generation tool, using the original render as geometry/camera reference. The yellow asset simulates a photographed FDM print; it is not a photograph of an actual 3D Fab customer part. Generated alpha is preserved. The sketch mask, printer reveal and parcel opening are local SVG animation driven by scroll, with complete static states for reduced motion.
